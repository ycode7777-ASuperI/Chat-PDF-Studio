# Chat-PDF-Studio
Hey there this is my Second upgraded Version of the First Repository where i have built a program that can filter a pdf based on year, this program specifically designed for the Whatsapp Export Chat Feature

Let Me Explain you the Program
Actually this program is built for specific domain people for their Matrimony businesses.
For those businesses that share the pdfs of biodata of brides and grooms to the customers.
When the biodata of bride and groom comes mixed in a whatsapp chat, it is possibly very hard to just sort and seperate the biodata of each gender in a single chat, basically when service provider provide the biodatas combinely in a single whatsapp chat. For building pdfs from scratch of the biodatas this program is meant to work
You just need to use a feature that Whatsapp enables it's users, 'Export Chat', by using this feature you will get a zip file containing all the data of biodata with their corresponding images, if selected 'including media' option.
You just need to upload the zip file from your device to this program, you need to fill some of the details about configuring your pdfs and then generate PDFs
If more then one pdf are generated, based on what you chose under 'biodata per pdf' field, then a zip file is produced containing all the pdfs, or a single pdf is produced
Remember that keeping the field empty means the cases other then what the filed needs, for e.g. if 'biodata per pdf' field is kept empty that triggers that the user want to append as many biodatas in a single pdf. Same for other fields too.
